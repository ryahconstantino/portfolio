# Бесплатные ресурсы Oracle Cloud

Oracle Cloud предлагает постоянно бесплатный тариф с широкими возможностями для обучения и размещения проектов.

## Постоянно бесплатные ресурсы

- **2 виртуальные машины AMD** — по 1 ГБ оперативной памяти и 1 OCPU.
- **4 виртуальные машины ARM** — суммарно 24 ГБ оперативной памяти и 4 OCPU.
- **200 ГБ блочного хранилища**.
- **10 ГБ объектного хранилища**.
- **10 ГБ трафика в месяц**.

## Создание виртуальной машины AMD

1. Откройте [консоль Oracle Cloud](https://cloud.oracle.com).
2. В меню перейдите в вычислительные ресурсы и экземпляры.
3. Выберите создание экземпляра.
4. Выберите образ Ubuntu или Oracle Linux.
5. Скачайте пару ключей SSH.
6. Создайте экземпляр.

## Создание виртуальной машины ARM (Ampere)

Процесс такой же, как для AMD, но в качестве конфигурации выберите Ampere. Подходит для круглосуточных приложений.

## Подключение по SSH

```bash
chmod 400 your-key.key
ssh -i your-key.key ubuntu@VM-IP
```

## Открытие порта в межсетевом экране

```bash
sudo iptables -I INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables-save
```
