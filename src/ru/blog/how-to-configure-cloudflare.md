# Как настроить Cloudflare

Cloudflare — платформа веб-сервисов, которая защищает и ускоряет соединение между пользователем и сервером сайта. У неё есть бесплатный тариф и простой интерфейс.

## Использование серверов имён Cloudflare

1. Создайте учётную запись Cloudflare и добавьте домен.
2. Откройте учётную запись у регистратора домена; если не знаете регистратора, воспользуйтесь WHOIS.
3. Укажите два сервера имён из учётной записи Cloudflare. Они имеют вид `x.ns.cloudflare.com`.
4. Дождитесь обновления — до 48 часов.
5. Затем настройте DNS с записями A и CNAME, если планируете использовать поддомены.
6. Для записи A укажите имя `@`, а в поле IPv4 — IP-адрес сервера.
7. Для поддомена `www` добавьте запись CNAME с именем `www` и целью `@`.

:::tip Простая смена сервера
С Cloudflare не нужно менять серверы имён при каждом переносе сайта. Достаточно обновить адрес IPv4 в записи A; распространение обычно занимает несколько минут.
:::

## Настройка межсетевого экрана веб-приложений

1. Откройте раздел безопасности, затем межсетевой экран веб-приложений и пользовательские правила.
2. Создайте правило и назовите его «Предотвращение спама и DDoS-атак».
3. В области выражения выберите редактирование выражения.
4. Добавьте выражение `(not ip.geoip.country in {"BR"} and not cf.client.bot) or (cf.threat_score gt 30)`. Оно назначает проверку посетителям не из Бразилии, кроме известных роботов, а также посетителям с оценкой угрозы выше 30.
5. Выберите действие: управляемая проверка или блокирование.
6. Поместите правило в начало списка.
7. Сохраните настройки и проверьте их через VPN; адаптируйте правило к своим потребностям.

:::tip Безопасность форм и защита от DDoS
Посетители, не соответствующие критериям межсетевого экрана, будут заблокированы.
:::
