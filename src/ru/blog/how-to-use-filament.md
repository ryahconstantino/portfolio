# Как использовать Filament

Filament — фреймворк административных панелей для Laravel. Он объединяет интерфейсы создания, чтения, изменения и удаления записей, таблицы, формы, фильтры, действия и панели показателей, не смешивая административные правила с публичным сайтом.

## Установка

В приложении Laravel, уже подключённом к базе данных, установите панель и создайте первого администратора:

```bash
composer require filament/filament:"^5.0"
php artisan filament:install --panels
php artisan make:filament-user
```

Установщик создаёт провайдер панели, обычно в `app/Providers/Filament/AdminPanelProvider.php`. Стандартная панель доступна по адресу `/admin`.

## Создание ресурса

Ресурс объединяет страницы списка, создания и редактирования модели Eloquent. Чтобы начать управление товарами:

```bash
php artisan make:filament-resource Product
```

Поля модели, таблицы и фильтры должны отражать правила предметной области. В каталоге цена, остаток, статус и публикация должны проверяться сервером, а не только отображаться в панели.

## Разделение панелей и разрешений

Приложение может иметь панель администратора по адресу `/admin` и панель оператора по адресу `/app`. Создавайте дополнительную панель, когда аудиториям нужны разные разрешения и навигация:

```bash
php artisan make:filament-panel app
```

Используйте политики Laravel и проверки авторизации в ресурсах, страницах и действиях. Пользователь не должен получать доступ к операции даже при прямом переходе по адресу.
