# Создание загрузочной флешки Linux: Debian, Ubuntu и Rocky Linux

Это руководство поможет подготовить установочную флешку для Debian, Ubuntu или Rocky Linux. Процесс **стирает все данные на флешке**: заранее сохраните её файлы и дважды проверьте выбранное устройство.

## 1. Скачайте официальный образ ISO и проверьте его

Скачивайте образ только с официальных сайтов [Debian](https://www.debian.org/distrib/), [Ubuntu](https://ubuntu.com/download) или [Rocky Linux](https://rockylinux.org/download/). Для большинства современных компьютеров Intel/AMD выбирайте архитектуру `amd64`, если не знаете, что устройство использует другую.

Если доступен файл контрольных сумм, проверьте ISO перед записью. В Linux:

```bash
sha256sum image-name.iso
```

Сравните результат с контрольной суммой, опубликованной дистрибутивом. Rocky Linux предоставляет файл `CHECKSUM` и описывает проверку командой `sha256sum -c CHECKSUM --ignore-missing`.

## 2. Запишите образ на флешку

Используйте флешку объёмом не менее 8 ГБ. Запись ISO отличается от копирования: инструмент должен записать загрузочный образ диска.

### В Windows или macOS

- **Ubuntu:** [официальное руководство](https://documentation.ubuntu.com/desktop/en/latest/how-to/create-a-bootable-usb-stick/) рекомендует программу записи образов; balenaEtcher работает на разных платформах.
- **Debian:** при использовании Rufus выбирайте режим **DD**, когда появится запрос. Режим ISO может изменить установочный образ.
- **Rocky Linux:** предпочтительны Fedora Media Writer или другая программа побайтовой записи образов. Rocky Linux не рекомендует Rufus и инструменты, не сохраняющие гибридные образы ISO.

Выберите ISO, подтвердите нужную флешку и начните запись. Дождитесь завершения проверки перед извлечением.

### В Linux с `dd`

Этот способ предназначен для тех, кто умеет определять диски. Подключите флешку и проверьте имя всего устройства, например `/dev/sdb`. **Не используйте раздел**, например `/dev/sdb1`:

```bash
lsblk --scsi
sudo umount /dev/sdX*
sudo dd if=/path/to/image.iso of=/dev/sdX bs=4M conv=fsync status=progress
sync
```

Замените `sdX` настоящим именем флешки. Выбор системного диска приведёт к его стиранию. Ubuntu также рекомендует проверять целевое устройство перед записью.

## 3. Загрузитесь с флешки

При выключенном компьютере подключите флешку и включите питание. Откройте меню загрузки: часто используются `F12`, `Esc`, `F2` и `F10`, но клавиша зависит от производителя. При наличии выберите вариант USB с UEFI.

- **Debian:** настройте язык, сеть, пользователей и разделы в установщике. Проверьте целевой диск перед подтверждением.
- **Ubuntu:** выберите пробный запуск или установку. Пробный сеанс позволяет проверить Wi-Fi, графику и периферию до изменения диска.
- **Rocky Linux:** выберите проверку носителя с последующей установкой, чтобы проверить образ. На экране назначения подтвердите диск и способ разметки.

## 4. После установки

По запросу извлеките флешку, перезагрузите компьютер и установите первые обновления. На сервере создайте обычного пользователя с правами `sudo`, настройте обновления безопасности и только затем открывайте в интернете сервисы вроде Nginx.
