# Освоенные технологии

Зрелый набор технологий — это умение выбрать подходящий инструмент, безопасно его эксплуатировать и измерить результат. Эти технологии я использую для создания, интеграции, наблюдения и развития цифровых продуктов.

### PHP

Веб-системы, API и деловые интеграции с акцентом на понятный, безопасный и сопровождаемый код.

### TypeScript

<TechnologyBanner name="TypeScript" category="Типизированный язык" />

Статическая типизация для предсказуемых клиентских и серверных приложений, особенно со сложными контрактами и интеграциями.

### Java

<TechnologyBanner name="Java" category="Корпоративные сервисы" />

Надёжные сервисы, корпоративные интеграции и приложения, которым полезны зрелая среда выполнения и экосистема.

<TechnologyBanner name="Laravel" category="Серверный фреймворк" />

Реактивные интерфейсы продуктов и составные компоненты с удобной разработкой и высокой производительностью.

### React

<TechnologyBanner name="React" category="Интерфейсы продуктов" />

Компонентные интерфейсы и приложения с предсказуемым состоянием и интеграцией API.

Практичное сопровождение и развитие существующих систем, основанных на работе с DOM и зрелых расширениях.

## Данные, очереди и хранение

### MySQL

<TechnologyBanner name="MySQL" category="Реляционная база данных" />

Реляционное моделирование, индексы, запросы и транзакции для коммерческих приложений и структурированных данных.

### MariaDB

<TechnologyBanner name="MariaDB" category="Реляционная база данных" />

Реляционные нагрузки с акцентом на эксплуатацию, резервное копирование, доступность и сопровождение схемы.

## Критерии архитектуры {#architecture-criteria}

При выборе технологии учитываются общая стоимость, эксплуатационные риски, безопасность, наблюдаемость, зрелость команды и будущее развитие. Цель — сокращать время реализации, не создавая эксплуатационного долга, который вредит бизнесу.
