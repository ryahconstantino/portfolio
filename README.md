# Personal Portfolio 2025

## Hotjar

The Hotjar tracking code is injected into every page only when `HOTJAR_SITE_ID` contains a numeric Site ID. It remains disabled when the variable is empty or invalid.

Copy `.env.example` to `.env.local` for local validation, or configure the same variable in the production environment:

```dotenv
HOTJAR_SITE_ID=1234567
```

Before enabling Hotjar in production, ensure the website's consent and privacy configuration matches the applicable requirements.
